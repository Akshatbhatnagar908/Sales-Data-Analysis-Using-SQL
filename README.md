# Sales Data Analysis Using SQL

This project focuses on analyzing a retail sales dataset using SQL. It demonstrates the use of SQL queries to explore key business insights such as sales trends, customer behavior, and product performance.

## 📁 Project Structure

- `sql project2.sql` — Contains all SQL queries used for data analysis.

## 🛠️ Skills & Concepts

- SQL Joins & Subqueries  
- Data Aggregation & Filtering  
- Grouping & Sorting  
- Business Insight Generation

## 🔍 Key Analyses

- Total sales by region and product  
- Top-performing products  
- Monthly and yearly sales trends  
- Customer segmentation based on purchases

## 📊 Tools

- SQL (Compatible with MySQL, PostgreSQL, or any RDBMS)  
- Any SQL-compatible database interface (e.g., pgAdmin, MySQL Workbench, DBeaver)

## 🚀 Getting Started

1. Import your dataset into a relational database.
2. Run the SQL queries from `sql project2.sql`.
3. Modify queries as needed to match your schema or expand the analysis.
